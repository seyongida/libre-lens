# Libre Lens 수익화 운영 안내

이 변경은 **직접 후원 광고를 게시할 준비**를 제공합니다. 실제 계약·입금·광고 네트워크 승인이 완료된 상태는 아닙니다. 광고 계정 ID나 정산 정보를 임의로 만들지 않습니다.

## 현재 구현

- `monetization.json`의 `sponsor.enabled`는 기본 `false`. 빈 광고 상자나 가짜 광고를 게시하지 않습니다.
- 활성화하면 빌드 시 시작 화면에 정적 텍스트 광고 한 개를 삽입합니다. 사진 분석 중에는 숨깁니다.
- 외부 스크립트, 원격 이미지, 노출·클릭 추적, 광고 쿠키를 사용하지 않습니다.
- 모든 이용자에게 같은 문구를 보여 줍니다. 사진·혈당값·파일명은 광고 설정에 전달하지 않습니다.
- `광고` 표시, 의료적 추천이 아니라는 설명, `rel=sponsored noopener noreferrer` 및 `referrerpolicy=no-referrer`를 자동 추가합니다.
- 개인정보·사용 가이드·후원 문의 페이지는 앱과 함께 오프라인 캐시됩니다.

## 첫 광고 게시

1. 후원사와 금액·기간·게시 문구·연결 주소를 협의합니다. 현재 버전은 노출/클릭 집계를 제공하지 않으므로 수치 기반 보장을 하지 마세요.
2. 수익화할 호스팅의 상업적 이용 조건을 확인합니다. GitHub Pages는 온라인 사업/상업 거래/상업용 SaaS 중심 호스팅에 제한이 있습니다. 광고 자체의 일괄 금지로 단정하지 않되, 본격 운영 시 상업 이용이 허용되는 호스팅을 선택하거나 GitHub에 사용 형태를 확인하세요.
3. 실제 계약한 정보로 `monetization.json`을 편집합니다.

```json
{
  "sponsor": {
    "enabled": true,
    "name": "실제 광고주 이름",
    "headline": "승인받은 소개 제목",
    "description": "과장된 의료 효능이나 보증을 포함하지 않는 소개 문구",
    "url": "https://example.com/"
  }
}
```

위 주소는 문서용 예시이며 실제 게시 때 반드시 교체합니다. 이름 60자, 제목 100자, 설명 240자, 주소 2048자 이내입니다. HTTPS 주소만 허용하며 로그인 정보가 들어간 주소는 거부합니다. 문구는 HTML로 실행되지 않게 이스케이프합니다.

4. `npm ci && npm run check`로 검증한 후 `dist/`를 게시합니다. JSON만 바꾸고 빌드하지 않으면 적용되지 않습니다.
5. 게시 기간 종료 시 `enabled: false`로 바꾸어 다시 빌드·배포합니다. 날짜 기반 자동 종료는 제공하지 않습니다. 오프라인 사용자는 재접속 전까지 캐시된 옛 문구를 볼 수 있으므로 이를 계약에 반영하세요.

## 호스팅 이전 준비

앱은 API·서버·비밀 키 없이 동작하는 정적 사이트입니다. Cloudflare Pages 같은 정적 호스팅에서는 저장소를 연결하고 빌드 명령 `npm run build`, 출력 폴더 `dist`, Node.js 22 이상으로 설정할 수 있습니다. 최초 설치는 `npm ci`가 필요하며 호스팅의 자동 의존성 설치 설정을 확인하세요. 현재 요금제의 상업 이용 약관·제한은 계정에서 확인하세요.

이전 후 `public/privacy.html`의 실제 호스팅 제공자와 개인정보처리방침 링크, README의 앱 주소를 갱신하세요. 새 도메인에서는 PWA를 다시 설치하고 OCR 캐시를 다시 준비해야 합니다. 기존 GitHub Pages 이용자에게 이전 주소를 안내하세요. 이 PR은 호스팅 계정 생성·이전·도메인 변경을 실행하지 않습니다.

## AdSense 등 광고 네트워크로 확장할 때

현재는 직접 후원 광고 방식이며 AdSense 코드·게시자 ID·`ads.txt`를 삽입하지 않습니다. 네트워크 광고를 원하면 실제 계정 개설 및 심사와 아래 작업이 추가로 필요합니다.

- 네트워크의 건강 관련 콘텐츠·민감정보·맞춤 광고 정책 확인
- 건강 데이터가 있는 분석 화면과 외부 광고 스크립트가 실행되는 문서/출처의 분리 검토 (화면에서 숨기는 것만으로 스크립트 접근이 차단되지 않음)
- 실제 데이터 처리에 맞는 개인정보 안내와 지역별 동의 관리 도입
- 공식 게시자 ID와 계정이 제공한 `ads.txt` 등록, 호스트 루트에서의 접근 검증
- 승인 후 실제 광고 노출·모바일 레이아웃·오프라인 동작 검증

광고 승인이 보장되거나 수익이 발생했다고 표현하지 않습니다. 방문자 수를 측정하지 않으므로 현재 수익 예측은 할 수 없습니다.
