사진과 분석값

선택한 이미지는 브라우저의 Canvas·Web Worker·로컬 OCR로 처리하며, 앱은 사진이나 추출한 혈당값을 서버로 전송하지 않습니다. 열린 탭의 메모리에서 사용하고 개인 사진·분석 결과를 LocalStorage나 IndexedDB에 자동 저장하지 않습니다.

현재 사진 지우기로 분석을 초기화할 수 있습니다. 내려받은 CSV와 원본 사진은 기기에 별도로 남으므로 직접 관리해야 합니다.

오프라인 저장

서비스 워커는 앱 코드, OCR 모델, 가상 샘플, 안내 페이지와 게시된 후원 문구를 캐시합니다. 사용자가 선택한 사진은 캐시에 넣지 않습니다. OCR 라이브러리는 언어 모델을 캐시할 수 있습니다.

브라우저의 사이트 데이터 삭제로 캐시를 지울 수 있습니다. 그 뒤에는 오프라인 사용 전에 다시 온라인으로 준비해야 합니다.

후원 광고와 외부 링크

후원 광고를 게시하는 경우 모든 이용자에게 같은 정적 문구와 링크를 표시합니다. 이 버전에는 광고 네트워크 스크립트, 추적 픽셀, 광고 쿠키, 방문 분석 도구를 포함하지 않습니다. 혈당값·사진·파일명으로 광고를 선택하지 않습니다.

광고주 사이트는 링크를 직접 눌렀을 때 새 탭에서 열립니다. 앱은 광고 링크에 사진·혈당값을 붙이지 않고, 리퍼러를 보내지 않도록 설정합니다. 이동한 사이트의 개인정보 처리는 해당 운영자의 정책을 따릅니다.

외부 광고 네트워크를 도입하는 경우에는 이 안내와 필요한 동의 절차를 먼저 갱신합니다.

호스팅과 문의

현재 공개 앱은 GitHub Pages에서 제공됩니다. 사이트 접속 과정에서 호스팅 제공자는 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인하세요.

문의는 저장소의 공개 이슈에서 받습니다. 공개 게시물이므로 스크린샷, 혈당 수치, 이름, 연락처 등 개인·건강 정보를 올리지 마세요.
