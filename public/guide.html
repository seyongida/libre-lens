LibreLink 스크린샷을 불러오고, 시간축을 확인하고, 손끝으로 탐색하세요.

무료로 시작하기 →
01 / IMPORT

자르지 않은 화면을 준비하세요

샘플과 같은 LibreLink의 밝은 세로 화면을 선택하세요. PNG를 권장하며 JPG·WebP도 사용할 수 있습니다. 최대 25MB, 5천만 픽셀까지 지원합니다.

다크 모드, mmol/L, 다른 앱의 그래프, 잘린 화면은 지원하지 않습니다. 먼저 앱의 사진 없이 샘플 체험으로 지원하는 화면을 확인하세요.

02 / CHECK

숫자보다 먼저, 축을 확인하세요

축 확인에서 읽어낸 시간과 원본 화면을 비교하세요. 인식이 불확실하면 오른쪽 끝 시각과 전체 시간(5–12시간)을 직접 설정합니다. 날짜는 판독하지 않으며 자정을 넘으면 ‘전날’로 표시합니다.

그래프를 터치하고 좌우로 움직이면 해당 지점의 시간과 추정 혈당이 표시됩니다. 키보드에서는 방향키, Shift + 방향키, Home·End를 사용할 수 있습니다.

03 / KEEP

필요한 기록만 직접 저장하세요

CSV 저장으로 추정값을 내려받을 수 있습니다. 앱을 새로 열면 사진을 다시 선택해야 하며, 현재 사진 지우기로 열린 분석을 초기화할 수 있습니다. 내려받은 CSV는 앱에서 삭제되지 않으니 직접 관리하세요.

설치하면 오프라인에서도

아이폰 Safari의 공유 → 홈 화면에 추가, 안드로이드 Chrome의 앱 설치 또는 홈 화면에 추가를 사용하세요. 설치한 앱에서도 첫 접속은 인터넷을 유지하고 ‘오프라인 준비 완료’를 기다리세요. 약 11MB의 앱·OCR 파일을 저장합니다.

브라우저가 사이트 데이터를 지우면 다시 온라인 준비가 필요합니다. 오프라인에서는 외부 광고주 링크나 GitHub 문의를 열 수 없습니다.

원본 측정값을 대체하지 않습니다

이 도구는 스크린샷의 선을 픽셀에서 환산합니다. 원본 센서 데이터를 복구하지 않으며, 해상도·압축·선 두께에 따라 차이가 생깁니다. 70–140 표시 구간은 원본 배경의 재현이며 개인의 치료 목표가 아닙니다.

치료·투약 결정에는 원래 앱과 의료진의 안내를 사용하세요. Abbott 또는 FreeStyle Libre와 제휴한 제품이 아닙니다.
