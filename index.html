시작하는 방법

1. 사진을 선택하세요

샘플과 같은 LibreLink 밝은 화면에서, 세로형 전체 스크린샷을 선택하세요. y축은 50–350 mg/dL, 곡선은 검은색인 레이아웃을 지원합니다.

2. 축을 확인하고 터치하세요

시간 눈금을 자동으로 읽습니다. 판독이 불확실하면 오른쪽 끝 시각과 전체 시간 범위를 직접 입력하세요. 그래프를 누른 채 움직이면 시간·추정 혈당이 따라옵니다. 키보드 좌우 방향키도 사용할 수 있어요.

3. 홈 화면에 설치하세요

아이폰: Safari에서 열기 → 공유 → 홈 화면에 추가 → 웹 앱으로 열기.
안드로이드: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가.

첫 접속에서 오프라인 준비가 완료되면 인터넷 없이도 사진을 분석할 수 있습니다. 마지막 분석 기록은 자동 저장하지 않으므로 앱을 다시 열면 사진을 다시 선택해 주세요.

Libre Lens는 Abbott 또는 FreeStyle Libre와 제휴하지 않은 독립 오픈소스 도구입니다.
